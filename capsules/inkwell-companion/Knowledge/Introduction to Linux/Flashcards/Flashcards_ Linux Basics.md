# Linux Basics Flashcards

---

## What does `pwd` do?
?
Prints the current working directory path.

---

## What is the difference between `cp` and `mv`?
?
`cp` copies files; `mv` moves or renames them.

---

## What does `ls -la` show?
?
Lists all files (including hidden) in long format with permissions, owner, size, and modification date.

---

## How do you create a new directory?
?
Use `mkdir directory-name`. Add `-p` to create nested directories.

---

## What does the `chmod` command do?
?
Changes file permissions. Can use symbolic (chmod u+x) or numeric (chmod 755) notation.

---

## What does `cat` do?
?
Displays the contents of a file to the terminal. Can also concatenate multiple files.

---

## How do you search for text inside files?
?
Use `grep pattern filename`. Add `-r` for recursive search across directories.

---

## What is the root directory in Linux?
?
The root directory is `/` — the top-level directory from which all other directories branch.
